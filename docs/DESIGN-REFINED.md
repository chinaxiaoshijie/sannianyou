## 〇、技术约束声明

**视觉能力上限：** 纪念碑谷风格——几何建筑、粉彩配色、BoxGeometry 组合、粒子系统、辉光后处理。

**设计中遵循的约束：**
- 所有装备外观 = 几何体组合 + 颜色变化 + 粒子效果。无复杂角色动画。
- 战斗特效 = 几何色块预警 + 粒子爆发 + 光柱 + 屏幕闪色。无高清贴图。
- BOSS 模型 = 几何体拼合（与建筑同一技术路线）。齿轮=圆柱体阵列，迷雾=半透明球体群。
- 视觉成长 = 灵光颜色/数量变化 + 装备几何体升级 + 粒子密度增长。玩家能看到，AI 能做到。

## 一、设计原则（重述 + 自检）

1. **知识即力量**：装备不加数值。装备改变你的学习方式或战斗策略。
2. **学以致用**：战斗中弹出的题目绑定当前 BOSS 阶段的学科。物理阶段出物理题。
3. **可见成长**：每一点进步 = 视觉变化。装备形态改变，不只是数字。
4. **协作大于竞争**：高一引入浅层跨学科连携。不设 PvP。
5. **正向循环**：修炼失败不丢道行。力竭回学舍。
6. **学科贯通**：跨学科连携从高一就有。不需要等到会考。

## 三、跨学科法则连携（高一浅层）

不需要等到会考。高一阶段就有 6 组基础连携：

| 连携 | 触发条件 | 效果 | 视觉 |
|------|---------|------|------|
| 匀变预判（物理）+ 函数映射（数学） | 预判落点 → 函数映射 | 预判准确率 70%→95% | 落点从蓝色箭头变为金色精准十字 |
| 渗透（生物）+ 氧化腐蚀（化学） | 削防 → 腐蚀 | 削防期间腐蚀伤害翻倍 | BOSS 半透明壳 + 橙色锈蚀同步扩散 |
| 热力抬升（地理）+ 自由落体（物理） | 气流柱 → 跃起 | 跃起高度翻倍，落地伤害 ×1.5 | 白色螺旋气流助推上冲 |
| 通译（英语）+ 破题（语文） | 翻译 → 审题 | 双重锁定弱点，暴击 ×2 | 金色准星 + 文字粒子环绕 |
| 年表（历史）+ 数列预判（数学） | 倒计时 → 数列推导 | 同时显示时间线和伤害序列 | 时间轴 + 数列并行显示 |
| 矛盾聚焦（政治）+ 周期透视（化学） | 矛盾 + 元素 | BOSS 核心矛盾与元素弱点同时高亮 | 红色核心 + 元素符号叠加 |

**连携触发机制：** 两人在 2 秒内先后释放 → 自动判定是否匹配。匹配成功 → 效果翻倍 + 全屏闪光。

### 5.2 答题蓄力（修正版）

**关键修正：题目绑定 BOSS 阶段学科。**

- 打机械面（物理阶段）→ 弹出物理题。范围：你对该 BOSS 造成的所有学科伤害中，物理题答对的部分蓄力 2 段（其他科 1 段）
- 打元素面（化学阶段）→ 弹出化学题
- 答对该科题目 → 你的该科法则槽高亮，下一击自动触发该法则

**蓄力视觉：** 角色脚下圆形蓄力槽（几何环），每段填满 1/3 亮起。3 段满 → 自动释放几何光柱冲击 BOSS。

### 5.4 法则视觉效果总表

**物理：** 蓝色色系。几何箭头（匀变预判）、弹簧几何体（弹力反震）、六边形冲击波（自由落体）。

**生物：** 绿色色系。螺旋链（肽链束缚）、绿色发光多面体（断能）、球形力场（核质封锁）。

**化学：** 紫色色系。橙色锈蚀纹理（氧化腐蚀）、紫色闪电（离子断裂）、银色钠块→爆炸（钠爆）。

**地理：** 黄色/青色系。白色螺旋粒子（热力抬升）、蓝色竖线雨幕（雨幕）、V 形裂缝（流水侵蚀）。

**数学：** 白色/金色系。几何圈（集合圈定）、坐标网格（几何困锁）、金色公式悬浮（函数映射）。

**英语：** 青色系。文字粒子（通译）、时钟几何体（时态转换）。

**语文：** 金色系。红色战场色调（意象召唤）、省略号几何体（赋格）。

**政治：** 红色系。红色高亮核心（矛盾聚焦）、金色光环（四个伟大）。

**历史：** 铜色系。时间轴几何体（年表）、技能残影重播（实证）。

## ⚡ MVP 范围定义（必读）

MVP 的唯一目标：**验证「一个知识→一场战斗」的核心循环是否成立。**

| 包含 | 不含 |
|------|------|
| 物理 1 科，7 条法则（L0-L3） | 其他 8 科 |
| 1 个 BOSS（遗忘·残卷，3 阶段） | 其他 BOSS |
| 1 个修炼建筑（实验室） | 其他建筑 |
| 3 件装备（练习册/错题集/状元笔记） | 衣冠/法器/其他经卷 |
| WASD 移动 + 空格闪避 + 法则触发 | 组队/连携/转职 |
| 心力/才气 HUD | 灵光/外观进化/商铺 |
| 修炼做题得道行+灵石+材料 | 灵石消费/丹药/强化 |

**MVP 验证的核心假设（按优先级）：**
1. 实时知识应用（答题不打断心流）能否实现？
2. 分层法则递进（L0→L3）能否制造足够的成长感？
3. 几何视觉在 10 分钟+ 战斗中是否审美疲劳？
4. 装备机制型效果是否改变了玩家行为？

## 一、前 5 分钟：新手引导设计 ⚡

### 1.1 目标
玩家下载后 5 分钟内完成：知道自己是谁→学会移动→完成第一次修炼→解锁第一条法则→知道下一步去哪。

### 1.2 时间线

**0:00-0:30 入场**
- 黑屏 → 淡入。镜头从高空俯冲至校门口。
- 屏幕中央一行字：「深圳中学高中园 · 三年游」
- 无需点击，3 秒后自动进入。

**0:30-1:30 身份确立**
- 角色站在校门口（大门建筑前）。
- 画面出现半透明引导文字：「你是高一新生。点击 WASD 开始你的三年旅程。」
- 没有 NPC 对话。没有剧情。没有"欢迎来到XX世界"。
- 学生按 W 向前走，穿过大门。

**1:30-2:30 第一次修炼**
- 走过大门后，一个发光箭头指向最近的建筑（实验室）。
- 接近实验室 → 屏幕出现提示：「按 E 进入实验室 · 修炼物理法则」
- 进入 → 弹出第一道物理题（L0 质点模型相关）
- 答对 → 获得道行 +5 + "你解锁了法则：质点聚焦"
- 答错 → "没关系，再试一次"
- 退出实验室。

**2:30-3:30 第一次法则使用**
- 退出后，屏幕出现提示：「按 C 打开人物面板」
- 面板中"质点聚焦"法则高亮闪烁。
- 提示：「拖拽法则到 1 号槽位装配」
- 装配完成 → 角色身上亮起第一道蓝色灵光（物理）。
- 提示：「你感受到了物理的力量。去校园深处寻找你的第一个考验吧。」

**3:30-4:30 遇 BOSS**
- 沿主干道向北走。在状元桥附近出现一个巨大的悬浮古籍几何体。
- 走近 → 屏幕变暗 → 显示 BOSS 名称：「遗忘·残卷」+ 下方一行小字：「你已装配法则：质点聚焦」
- 提示：「按 E 挑战」

**4:30-5:00 战斗开始**
- 进入战斗模式。镜头拉近，WASD/空格/1键提示出现在屏幕底部。
- BOSS 发出第一个预警（红色扇形）。玩家第一次闪避。

### 1.3 设计原则
- **零文本叙事。** 没有NPC对话、没有世界观介绍。全靠视觉引导（发光箭头、高亮物体、半透明提示）。
- **5 分钟到第一次战斗。** 这是最重要的指标。学生下载后 5 分钟内必须进 BOSS 战。
- **失败友好。** 如果被打败，回学舍，保留已解锁的法则和道行。NPC 提示：「再试试——你比以前更强了。」
- **不教太多。** 只教：WASD、空格闪避、1键法则、E键交互。其他自己发现。

## 二、世界观

高中 = 自我强化的三年。九门学科 = 世界的九条底层法则。

你在学府中修炼。以知识为力量，以考试为试炼。每一次修炼都在积累道行，每一次 BOSS 战都在验证你所学的能否转化为真正的力量。

---

## 三、设计原则（不可变）

1. **知识即力量**：学会 F=ma ≠ +5 攻击。学会 F=ma = 看到 BOSS 质量面板、计算暴击窗口。装备不加数值——只改变你的行为方式。
2. **学以致用**：战斗中知识应用不中断心流。答题不是弹窗，是战斗动作的有机部分。
3. **可见成长**：每一点进步 = 视觉变化。法则解锁 = 灵光显现。装备强化 = 几何体进化。
4. **协作大于竞争**：不设 PvP。法则连携让不同知识体系互补。
5. **正向循环**：失败不丢道行。每次尝试都在积累。
6. **学科贯通**：知识之间是互通的。连携从新手期就可见（通过 AI 同伴）。

## 五、九门学科法则体系

### 5.1 分层结构

| 层 | 时机 | 类型 | 说明 |
|----|------|------|------|
| L0 | 入学 | 感知 | 认识世界。改变你看到的信息。 |
| L1 | 期中前 | 基础操作 | 改变世界。最基础的动作能力。 |
| L2 | 期末前 | 进阶操作 | 更复杂的操作能力。 |
| L3 | 高一下 | 组合应用 | 开始整合多个概念。 |

### 5.2 法则设计准则

每条法则必须是"规则型"而非"数值型"。数值型（+20% 伤害）必须被转换成视觉/行为规则。

**❌ 坏的法则：** 「全队伤害 +20%」
**✅ 好的法则：** 「BOSS 身上出现两个攻击目标——打主要目标才有伤害，打次要目标伤害归零」

### 5.3 物理（MVP 完整实现 ⚡）

| 层 | 法则 | 知识点 | 战斗效果 |
|----|------|--------|---------|
| L0 | 质点聚焦 | 质点模型 §1.1 | 镜头拉近 BOSS 核心，暴露结构细节（线框高亮） |
| L1 | 匀变预判 | 匀变速直线运动 §2.2 | 地面显示 BOSS 下一落点预测（蓝色几何箭头） |
| L1 | 自由落体 | 自由落体 §2.4 | 跃起后下落速度递增，落地六边形冲击波 |
| L2 | 弹力反震 | 弹力 §3.2 | BOSS 近战命中时被弹开（弹簧几何体弹出动画） |
| L2 | 摩擦场 | 摩擦力 §3.3 | 地面生成橙色六边形区，BOSS 移速 -40% |
| L3 | 精确打击 | F=ma §4.3 | BOSS 头顶显示质量数字。速度 × 质量 = 暴击倍率 |
| L3 | 惯性闪避 | 牛顿第一定律 §4.1 | 闪避后身后留蓝色残影轨迹，速度 +30% |

### 5.4 其他学科（P2）

生物/化学/地理/数学/英语/语文/政治/历史 — 各 6-7 条法则，结构同物理。

### 5.5 法则连携（P2）

跨学科连携表在高一阶段通过 AI 同伴展示，玩家亲自参与从会考 BOSS 开始。

## 六、战斗系统

### 6.1 ⚡ 战斗中的知识应用（实时机制）

**关键修正：取消弹窗答题。知识应用融入战斗动作。**

**旧设计（废弃）：** 站定→按E→弹窗选择题→答对→蓄力。

**新设计（MVP）：**

战斗中，知识应用通过以下方式实现，**不中断心流**：

**方式一：视觉信息 = 知识应用**

法则装配后自动生效。装配"质点聚焦"→ BOSS 核心自动高亮。装配"匀变预判"→ BOSS 落点自动显示箭头。学生不需要"答题"来激活——**装配法则本身就是知识的选择和应用。**

**方式二：时机动作 = 知识验证**

Boss 暴露出弱点窗口时，学生需要在动作层面做出正确反应：
- BOSS 头顶闪烁质量数字"m=50kg"——学生在 1.5 秒窗口内冲到 BOSS 侧面按 1→ 触发精确打击
- 不按 → 窗口错过 → BOSS 释放大招
- **选择是否按键、何时按键、在哪个位置按键——这才是"运用知识"**

**方式三：修炼中做题 = 法则解锁**

知识的学习和验证发生在修炼建筑中（见 §七）。BOSS 战中使用已解锁的法则。两个系统分离但互补。

### 6.2 操作层 ⚡

| 操作 | 键位 | 细节 |
|------|------|------|
| 移动 | WASD | 8 方向。默认正交等距视角，Tab 切自由。 |
| 闪避 | 空格 | 0.2 秒无敌帧，冷却 1.5 秒。身后留半透明几何残影。 |
| 法则 1/2/3 | 1/2/3 | 0.3 秒抬手动作。冷却环形倒计时显示在法则图标上。 |
| 修炼 | E | 站定后进入修炼模式（答题界面）。仅修炼建筑内可用。 |

### 6.3 BOSS 攻击预警（几何色块）⚡

| 类型 | 预警 | 视觉 |
|------|------|------|
| 近战横扫 | 红色扇形 0.8 秒 | 半透明红色三角几何片 |
| 远程投射 | 红色弹道线 1.0 秒 | 红色虚线 + 末端圆点 |
| 范围打击 | 红色圆形 1.2 秒 | 红色半透明六边形地面纹 |

### 6.4 心力/才气 ⚡

| 事件 | 心力变化 | 才气变化 |
|------|---------|---------|
| 每秒自然回复 | +0.5 | +0.3 |
| 被 BOSS 攻击命中 | -BOSS 攻击值 | — |
| 释放法则 | — | -法则消耗 |
| 阶段击破 | +30% | +50% |
| 力竭 | 归零 → 回学舍 | 保留 |

## 七、修炼系统 ⚡

### 7.1 MVP 修炼建筑：实验室

- 进入 → 答题界面
- 题库：物理题（按章节索引）
- 答对 → 道行 +5 + 灵石 +3 + 纸屑（70%概率）
- 答错 → 无惩罚，下一题
- 每日前 10 题双倍奖励
- 物理 KP 达标 → 自动解锁对应法则

### 7.2 道行（KP）里程碑

| 总 KP | 解锁 |
|-------|------|
| 0 | 法则槽×1，L0 法则解锁 |
| 10 | L1 法则×2 解锁 |
| 25 | L2 法则×2 解锁 |
| 40 | 法则槽×2 |
| 60 | L3 法则×2 解锁 |

## 八、装备系统 ⚡

### 8.1 设计铁律

> 装备不加任何数值。装备只改变你的行为方式或信息获取。

### 8.2 MVP 装备（经卷）

| 档 | 名称 | 品质 | 总 KP | 效果 | 外观 |
|----|------|------|-------|------|------|
| 1 | 练习册 | 普通 | 0 | 修炼错题记录。同类题型下次时限+3秒 | 白色方块 |
| 2 | 错题集 | 稀有 | 30 | 同一 BOSS 每失败一次，对其永久伤害+5% | 蓝色封面+银色书脊 |
| 3 | 状元笔记 | 传说 | 80 | 修炼答题时限×1.5 | 金色辉光+全息投影 |

### 8.3 P2 装备

衣冠（防具）+ 法器（饰品）在 MVP 后扩展。同样遵循机制型设计——不加数值，改变行为。

## 十、题库架构 P2

### 10.1 题目格式

```json
{
  "id": "phys_l1_001",
  "subject": "物理",
  "chapter": "§2.2 匀变速直线运动",
  "law": "匀变预判",
  "difficulty": 1,
  "question": "一辆汽车以 10 m/s 的初速度匀加速行驶，加速度为 2 m/s²，3 秒后的速度是多少？",
  "options": ["13 m/s", "16 m/s", "19 m/s", "22 m/s"],
  "correctIndex": 1,
  "explanation": "v = v₀ + at = 10 + 2×3 = 16 m/s",
  "timeLimit": 15
}
```

### 10.2 生产管线

- MVP 阶段：手动编写 50 道物理题
- P2 阶段：与学科老师合作，每科 100+ 题
- 质量标准：每题标注教材章节 + 关联法则 + 难度等级

## 十一、经济系统重设计 P2

### 11.1 知识绑定经济

灵石获取与知识掌握深度挂钩：
- 物理 KP 越高 → 物理 BOSS 灵石掉落越多
- 偏科生需要通过协作弥补经济劣势

### 11.2 稀缺性设计

- 灵石消耗：强化装备 + 购买丹药 + P2 解锁法则槽
- 丹药携带上限 → 制造"买哪个"的选择压力
- 不在 MVP 阶段过度设计

## 十三、技术约束
